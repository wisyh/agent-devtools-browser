# Changelog

## 0.1.0 — 2026-11-17

Initial release.

- Real Edge/Chrome launch with `--remote-debugging-port` and
  `--auto-open-devtools-for-tabs`.
- MCP stdio server with `browser` and `browser_devtools` tools.
- Portable Agent Skill in `skill/SKILL.md`.
- CLI with a persistent browser session file.
- Optional DeepSeek Harness Host adapter, no sidebar entry.
- CDP-backed navigation, DOM snapshots, clicks, typing, waits, tabs,
  JavaScript evaluation, structured extraction, CSS inspection, console and
  network capture, storage, performance, and screenshots.
